# 时间小工具 · slide-clock

一个纯前端的时间小工具站，包含四个页面：

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 滑动时钟 | `/` | **拖动 24 小时表盘选一个时刻，立刻知道从现在到那一刻还隔多少小时、多少分钟。** |
| 万年历 | `/calendar/` | **公历 / 农历 / 藏历 / 回历 / 干支 / 节气 / 月相 / 宜忌 / 八字排盘，一屏看完。** |
| 日期查询 | `/calendar/query.html` | **公历 ↔ 农历互查，带四柱、节气、星宿、纳音。** |
| 倒数日 | `/countdown/` | **选一个日期，看看已经过去多少天，或者还要等多少天。** |

## 万年历

页面沿用 [tyme4ts](https://github.com/httcup/tyme4ts) 仓库 `docs/` 里自带的万年历与日期查询页（tyme4ts 为 MIT 协议），只把页头换成站内统一的版式：

- 大号「今日」卡片：公历日、星期、农历、干支，右侧列出星座 / 节气物候 / 日主五行 / 值神建除 / 纳音 / 九星
- 信息卡：节气、月相、六曜、星宿、冲煞、胎神、彭祖百忌、小六壬、藏历、回历、法定假日
- 宜 / 忌 / 神煞全量列出，右侧可改日期时间做**八字排盘**（四柱、纳音、胎元、胎息、命宫、身宫）
- 底部月历可点选任意一天，翻月查看，节气与节日标色
- 历法计算使用 [tyme4ts](https://github.com/6tail/tyme4ts)（MIT），已打包为 `calendar/tyme.min.js`（IIFE，全局 `Tyme`）随站点托管；若该文件缺失会自动回退到 jsDelivr 上的官方 npm 包

## 倒数日

- 过去的日子显示「已经过去 xx 天」，未来的日子显示「还有 xx 天」，当天显示「就是今天」
- 大号天数 + 月历联动：点月历上任意一天即可切换目标日期，可翻月
- 日期**分段直接输入**：年 / 月 / 日 三个格子，输完年自动跳到月、月输完自动跳到日，单数字自动补零（输 `9` 得 `09`），退格可逐段回退
- 支持整段粘贴：`1995-12-23`、`1995/12/23`、`19951223`、`1995年12月23日` 都能识别；不存在的日期（如 2 月 30 日）会抖动提示并还原上一个有效日期
- 也可以点右侧日历图标用系统日期选择器，或直接点页面上的月历
- 快捷项自动显示**最近的 3 个法定节假日**（内置 2026–2029：元旦 / 春节 / 清明 / 劳动节 / 端午 / 中秋 / 国庆）
- 附加换算：**相差 X 年 Y 个月 Z 天**、折合几周几天、约几个月几天、一年中的第几天（按日历借位，不是 ÷30 的估算）
- URL hash 分享（`#2026-12-31`）

## 功能

- 🕐 **滑动表盘**：24 小时刻度，拖动即可选到任意分钟（1 分钟精度），也支持键盘方向键微调
- 📅 **今天 / 明天**：可选范围从「此刻」一直到**次日 23:59**；滑到已经过去的时刻会自动顺延到明天
- ⏱ **实时倒计时**：结果自带秒级倒数，页面开着就一直更新
- 🎯 **常用时刻**：06:30 / 07:00 / 07:30 / 08:00 / 11:30 / 12:00 / 17:30 / 18:00，一键跳转
- 🔗 **可分享**：当前选择会写进 URL hash（`#t=450&d=0`），复制链接即可还原
- 📱 **响应式**：手机、平板、桌面都排得下
- 🔒 **零依赖**：单个 HTML 文件，所有计算在本地完成，不上传任何数据

## 计算规则

目标时刻取「顺时针最近一次到达」：

```
间隔 = 目标时刻 - 现在（若为负，则 +24 小时）
```

由于可以选择「今天 / 明天」，最远可以算到次日 23:59，最长间隔约 47 小时 59 分钟。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建。

```bash
# 或者起个本地服务
python3 -m http.server 8080
```

| 项目 | 值 |
| --- | --- |
| Framework preset | None |
| Build command | *(留空)* |
| Build output directory | `/` |

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 表盘用 SVG 绘制，指针角度 = `分钟数 / 1440 × 360°`
- 时间全部基于浏览器本地时区计算
