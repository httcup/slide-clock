## 滑动时钟（slide-clock）工具站

- 需求：滑动时钟，算「现在 → 滑动选中的时刻」间隔；页面要简洁好看、配色舒服；表盘可滑到次日 23:59。
- 实现：单文件 `index.html`（原生 HTML/CSS/JS，无构建）。24 小时刻度 SVG 表盘（24 个刻度 + 24 个数字，避免被误读成 12 小时钟），拖拽选时刻（1 分钟精度），今天/明天分段切换，金色"现在"点位 + 渐变弧线从现在顺时针扫到目标；面板显示 X 小时 Y 分钟、总分钟、目标日期、秒级倒计时、±1/±5 分、常用时刻（07:00/09:00/12:00/18:00/23:00）；选择写入 URL hash `#t=<分钟>&d=<0|1>`。
- 关键规则：目标取"顺时针最近一次"，滑到已过去的时刻自动顺延到明天（单向，回今天需点"今天"）；步进上限 2879 分钟 = 次日 23:59。
- 部署：GitHub `httcup/slide-clock`（public，main）→ Cloudflare Pages 项目 `slide-clock`（Git 集成，无构建命令）→ https://slide-clock.pages.dev
- 踩坑记录：
  - 无头 Chrome 在 macOS 最小窗口宽 500px，用 414 宽截图会被裁切误判为"横向溢出"；校验窄屏要在 iframe 里指定宽度渲染。
  - 表盘"现在"点位角度曾写成 `秒/1440*360`，应为 `秒/86400*360`。
  - GitHub MCP 集成令牌无建仓权限（403 Resource not accessible by integration）；本机钥匙串存有 ghp_ 经典 token（repo 权限），走 REST API 建仓 + SSH 推送可用。
  - Cloudflare 用 wrangler OAuth token 直接走 API 建 Git 集成项目可行（账户已装 GitHub App），新建项目不会自动构建，推一个空提交即可触发。
