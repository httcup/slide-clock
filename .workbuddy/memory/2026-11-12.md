## 新增倒数日页面（第二个工具）

- 页面：`countdown/index.html`，线上 https://time.139t.cn/countdown/（带不带尾斜杠都 200）。
- 站位：首页页头右上角加 `.nav-link` 胶囊「倒数日 →」（header 改为 `.head` + `.head-text` 两栏 flex，移动端自动折行），倒数日页对应「← 滑动时钟」回链 `../`。
- 逻辑：`dayDiff` 用 UTC 日期差避免时区/DST 误差；diff>0「还有 xx 天」，diff<0「已经过去 xx 天」，0「就是今天」；另附折合周数、约几个月几天、一年中第几天。
- 版式：工具栏（原生 date 选择器 + 快捷项）+ 左侧大号天数 + 右侧可点选月历（可翻月，选中填色，今天描金框）。移动端月历置顶（order:-1）。
- 实测：2026-01-01 → 已经过去 315 天；2026-12-31 → 还有 49 天；+100 天后 = 2027-02-20。
- 坑：`new Date('2026-01-01')` 会按 UTC 解析导致跨时区偏移，统一用 `parseISO()` 手动构造本地日期。

## 倒数日第二次迭代：节假日快捷项 + 日期直接输入

- 快捷项由「今天 / 两个固定日期 / 100 天后」改为**动态计算最近的 3 个法定节假日**：`HOLIDAYS` 表内置 2026–2029 七个法定节日（元旦/春节/清明/劳动节/端午/中秋/国庆），`upcomingHolidays(3)` 取 >= 今天的最早三条，chip 显示「名称 MM-DD」，`chipSig` 变化才重建 DOM。日期已核：2027 春节 2/6、清明 4/5；2028 春节 1/26、清明 4/4；2029 春节 2/13。
- 日期输入问题修复：原生 `<input type="date">` 年份段输入会把数字挤到月/日段，输 1995 变成 1904。改为可见 text 输入 + 隐藏的原生 date 覆盖在日历图标上（点击即系统选择器，无需 showPicker）。
- `parseLoose()` 支持 `1995` / `1995-12` / `1995-12-23` / `1995/12/23` / `19951223` / `1995年12月23日`；年月日分别校验（含闰年），非法值抖动 + 还原上一有效值；输入过程中能解析就即时生效，聚焦时不回写输入框（`document.activeElement !== dt`）。
- 注意：`new Date(1995, ...)` 正常，但年份 0-99 会被映射到 19xx，统一用 `setFullYear` 构造。
